CSIS 118B · UNIT 5

Compare. Test. Choose a path.

One pair of bit patterns. Two interpretations. Predict how the flags steer a conditional jump.

This is a simulation of one register-to-register CMP or TEST followed immediately by a jump, not a full emulator. It does not execute your programs or model memory and library calls.

1. Set the operands and jump

Use decimal (negative allowed), 0x hexadecimal or 0b binary (unsigned patterns). No fractions, expressions, or negative hex/binary. All operand calculations use exact integers.

Choose a prediction, then reveal the decision.

2. Read the same bits two ways

CMP and TEST leave both operands unchanged, including upper register bits. CMP forms a temporary subtraction; TEST forms a temporary bitwise AND. Only flags survive: neither temporary result is stored in a register.



3. Follow the flags
Both paths end at .done. On fall-through, jmp .done skips the taken block. A conditional jump reads flags without changing them.


Connect the rule to the question
  • After CMP A, B, JE means equal; JL means signed A < B; JB means unsigned A < B. JL uses SF != OF, not SF alone.
  • After TEST A, B, JE means the AND result is zero: the operands share no set bits. It does not mean A equals B. TEST clears CF and OF, so unsigned-comparison jump names no longer describe a comparison of A and B.
  • JZ is an alias of JE; JNZ is an alias of JNE. PF reflects even parity of the low byte only. TEST leaves AF undefined.
  • Keep the jump next to its flag-setting instruction. Playground print helpers may clobber flags and working registers. Branch first; preserve needed values before printing.
