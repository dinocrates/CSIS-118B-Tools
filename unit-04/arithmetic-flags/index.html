Arithmetic and flags lab

ADD, SUB, INC, DEC, and NEG at 8/16/32/64 bits — exact CF/OF/ZF/SF, with AF/PF as a secondary reference.

How to use this tool

  • CF reports unsigned carry/borrow; OF reports signed range failure; ZF tests zero; SF reports the result's high bit. ADD and SUB compute both CF and OF from the same operation — there is no separate signed/unsigned ADD instruction.
  • INC/DEC preserve whatever CF already was; NEG and SUB compute CF fresh. Watch the "(preserved)" label.
  • This is a teaching model of one instruction at a time, not a running program.

Set up the operation

A field accepts a signed decimal spelling or an unsigned bit pattern for the chosen width (e.g. byte -1 and byte 0xFF select the same eight bits).

Worked context — a short ADD/SUB sequence

base=100, fee=25, credit=10. Loading base, adding fee, then subtracting credit gives EAX values 100 → 125 → 115. Source memory is unchanged until a store.

mov eax, 100       ; EAX = 100
add eax, 25        ; EAX = 125
sub eax, 10        ; EAX = 115
Ready. Default: 8-bit ADD, A=127, B=1, incoming CF=0.
