Zero/sign extension across widths

Generalizes the Unit 3 byte-interpretation tool's fixed 8-bit→EDI/RDI scenarios to any source width, any destination width, and MOVSXD.

How to use this tool

  • Pick a source width/value and a destination width, then choose zero-extend (MOVZX-style) or sign-extend (MOVSX/MOVSXD-style).
  • A 32-bit destination write also clears the parent 64-bit register's upper half; a 64-bit destination write is the full parent register. This is the MOVSX-to-EDI "trap."
  • For the single fixed 8-bit source case with a bit-toggle UI, see the linked Unit 3 tool below — this page adds the general width picker and MOVSXD, which that tool does not have.

Related Unit 3 tool (reused, not duplicated)

Unit 3's Byte interpretation and extension tool already covers unsigned/signed readings of a single toggle-able byte and its MOVZX EDI / MOVSX RDI / MOVSX EDI widening. Use it for that interactive bit-by-bit exploration; use this page for other source widths, other destination widths, and MOVSXD.
