Unit 4 — Data Movement and Arithmetic

Four new standalone tools, plus two verified-reuse pages built on top of Unit 3's existing models. Each works on its own page and can also be embedded in a Canvas page with ?embed=1.

Movement instruction lab

Step curated MOV/XCHG trace scenarios (memory copy, register exchange, a failed two-MOV "swap", memory exchange through a register, and three partial-register writes), plus a curated MOV-form legality bank. Lecture placement: Data Movement, U04-01/02/03/05.

Open tool

Arithmetic and flags lab

ADD/SUB/INC/DEC/NEG at 8/16/32/64 bits with exact CF/OF/ZF/SF, and AF/PF as a secondary reference. Lecture placement: Arithmetic, U04-07/08/09/10.

Open tool

Multiplication register-pair lab

One-operand full-product MUL/IMUL and truncated two-/three-operand IMUL, with exact 2w-bit products and the CF/OF overflow rule. Lecture placement: Arithmetic, U04-11/12.

Open tool

Division preparation lab

Narrow-value or manual high:low dividend preparation, exact DIV/IDIV, and divide-error detection (zero divisor or an out-of-range quotient). Lecture placement: Arithmetic, U04-13/14/15.

Open tool

Zero/sign extension across widths (verified reuse + fallback)

Unit 3's Byte interpretation and extension tool is the primary reuse for the single fixed-byte, bit-toggle case. It does not offer a general source/destination width picker or MOVSXD, so this page adds that as a small supporting tool, built on the same ideas. Lecture placement: Data Movement, U04-04.

Byte offsets, arbitrary access, and store (verified reuse + fallback)

Unit 3's Storage-layout explorer is the primary reuse for width/initializer selection and an element's byte offset. It does not offer an arbitrary offset+width access independent of element boundaries, or a store simulation, so this page adds those directly on top of the Unit 3 model (not a duplicate). Lecture placement: Data Movement, U04-06.
