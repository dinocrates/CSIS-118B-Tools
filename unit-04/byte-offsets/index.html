Byte offsets, arbitrary access, and store

Adds an arbitrary byte-offset + access-width read (independent of element boundaries, with out-of-bounds detection) and a store simulation on top of Unit 3's storage-layout model.

How to use this tool

  • Define 1–8 initializers at a chosen element width, then read an arbitrary byte offset at an arbitrary access width — a raw byte offset is not an element number.
  • Store simulates writing a new value into one existing element and re-renders the little-endian byte layout.
  • An access that would run past the end of the declared storage is flagged; this tool does not claim the CPU checks bounds automatically.

Related Unit 3 tool (reused, not duplicated)

Unit 3's Storage-layout explorer already covers width/initializer selection, an element's byte offset, and the little-endian layout. This page is built directly on top of that tool's own model (unit-03/shared/storage-layout.js, reused via require/script tag, not duplicated) and adds two things it does not have: an access at an arbitrary offset/width independent of element boundaries, and a store simulation.
