CSIS 118B · UNIT 10

Which bytes belong to this element?

Separate an element index, a byte offset, an address, and the value loaded from that address.

This is an exact-integer teaching model. Addresses are illustrative unsigned 64-bit arithmetic, not actual playground addresses or a test of processor address validity. No memory is accessed and no code is executed. Every requested index is checked before a load is modeled.

1. Describe the array

Decimal or 0x hexadecimal. The entire allocated range must fit unsigned 64-bit arithmetic; no wraparound is simulated.

Separate values with commas or spaces. Each must fit the selected width: signed minimum through unsigned maximum. Negative values use two’s complement. Positive bit patterns may have a negative signed interpretation.

Capacity is the number of supplied elements. Active length may be zero and may be smaller than capacity. An element outside the active prefix is not a valid requested load.

Make a prediction

Leave blank to predict bounds only. For a rejected index there is no loaded value.

2. Check bounds, then calculate

Array layout: low addresses to high addresses

Bytes are shown in increasing address order. SELECTED marks the admitted element; INACTIVE marks allocated elements outside the active prefix. The input values remain unchanged by a load.

Address is not value
Compute base + index × width to locate the element. For WORDs, element index 1 means byte offset 2; it is not “index 2.” Use lea r12,[rel values] to obtain the base, then a register-based operand such as [r12+r14*4]. RIP-relative addressing cannot also contain a scaled index: do not expect [rel values+r14*4] to encode that combination.
lea rdi,[r12+r14*4] computes an address. movsxd rdi,dword [r12+r14*4] reads and sign-extends a value. For BYTE/WORD use MOVSX or MOVZX; for a DWORD, writing EDI zero-extends into RDI while MOVSXD sign-extends. A QWORD already fills 64 bits: the print helper’s signed or unsigned interpretation determines the displayed number.
Out-of-bounds machine-code access might fault or access unrelated memory. This model rejects it and displays no selected address or loaded value. It does not claim a predictable result for invalid memory access.
