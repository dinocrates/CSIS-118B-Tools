Load–compute–store tracer

Predict which state changes after each instruction, then step through LEA, a load, ADD, and a store.

How to use this tool

  • Set an initial count and an addend, then Apply / Reset to start a new trace.
  • Predict whether EAX, RBX, count, or result changes, then click Step instruction to reveal it.
  • This is a teaching model: address 0x1000 is illustrative, not an actual x86 Playground address.

Set up the trace

count accepts 0 through 4294967295 (decimal, or 0x/0b/0o).

addend accepts 0 through 100000.

Instruction sequence

Initialized data (illustrative): count: dd 100 and result: dd 0. Ordinary MOV cannot copy directly between two memory operands — that is why the sequence loads count into EAX before it can be stored anywhere else.
