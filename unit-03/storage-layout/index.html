Choose an element width and initializer list. Predict the total bytes and a byte offset before revealing the layout.

How to use this tool

  • Pick a width (db/dw/dd/dq) and 1–8 integer initializers.
  • Choose a zero-based element index, then Reveal layout.
  • Offsets are relative to the data label — this model emits contiguous values with no padding or alignment, and does not fabricate process addresses.

Why this matters

  • NASM does not retain a label's data definition as a type check for later accesses — a too-wide memory access can read neighboring bytes.
  • In the default dd 10, 20, 30, 40 array, offset 0x0B (11 decimal) does not start the fourth DWORD; only offset 12 (0x0C) does.
