Byte interpretation and extension

Set an 8-bit pattern, then compare unsigned and signed readings, and three ways of widening it into a 64-bit register.

How to use this tool

  • Toggle a bit, or load a byte pattern by decimal, 0x hex, 0b binary, or 0o octal.
  • A negative input is not a byte pattern — signed interpretation is an output, computed from the stored pattern.
  • Compare MOVZX and MOVSX into RDI/EDI on the same stored byte.
