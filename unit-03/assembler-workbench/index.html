Assembler phase workbench

Compare fixed NASM examples at preprocessing, assembly, and runtime.

How to use this tool

  • Choose an example, predict which phase changes or evaluates its value, then reveal preprocessing, assembly, and runtime one at a time.
  • This is a teaching model that selects known, fixed examples; it does not evaluate arbitrary source code.
  • Changing the example resets it back to the predict-before-reveal state.
