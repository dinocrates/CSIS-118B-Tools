Unit 3 — Memory, Data Representation, and the Assembler

Five standalone browser tools. Each one works on its own page and can also be embedded in a Canvas page with ?embed=1.

Load–compute–store tracer

Step a fixed LEA / load / ADD / store sequence and predict which of EAX, RBX, count, and result changes after each instruction. Lecture placement: Page 1, videos U03-05/06.

Open tool

Storage-layout explorer

Choose a DB/DW/DD/DQ width and 1–8 initializers, then predict the total bytes and an element's byte offset before revealing the little-endian layout. Lecture placement: Page 2, U03-07/09/10.

Open tool

Byte interpretation and extension

Compare unsigned and signed readings of one stored byte, and three ways (MOVZX/MOVSX into RDI or EDI) of widening it into a 64-bit register. Lecture placement: Page 2, U03-08.

Open tool

String bytes and length explorer

Count visible ASCII characters versus storage bytes versus $ - label, with safe NASM source generation for strings containing quotes. Lecture placement: Page 2 U03-11, and again at Page 3 U03-15.

Open tool

Assembler phase workbench

Compare five fixed NASM examples (EQU, %define, grouped %define, %assign, and runtime ADD) at preprocessing, assembly, and runtime. Lecture placement: Page 3, U03-14/16/17.

Open tool

Register-width review (reused from Unit 2)

The lecture's brief width review reuses the existing Unit 2 register-alias explorer rather than a new sixth tool. It shows MOV writes through RAX/EAX/AX/AH/AL from a starting 0x1122334455667788, and which bytes are written, zero-extended, or preserved.
