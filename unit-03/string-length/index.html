String bytes and length explorer

Count visible ASCII characters, storage bytes, and the assembly-time span measured by $ - label.

How to use this tool

  • Enter 0–40 printable ASCII characters (codes 32–126); this model does not handle Unicode/UTF-8.
  • Toggle whether a line feed (10) and/or a NUL terminator (0) are appended, then Reveal.
  • Visible characters, storage bytes, and MESSAGE_BYTES are three different counts — do not assume they are always 2 apart.
  • The text character "5" is stored as ASCII code 53 (0x35), not the number 5 — typed text and a numeric byte value are different things.
