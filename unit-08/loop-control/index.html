3. Explain the result



Keep the condition and its meaning together
  • Pretest sentinel: first read a candidate, validate it, then check whether it is zero. Zero is neither added nor counted. Continue while nonzero means JE sentinel exits on zero. A separate five-value cap prevents unbounded processing.
  • Posttest guess: read and accept a valid guess before testing success. Repeat until equal means repeat while unequal: JNE body. Success on the third accepted attempt wins because success is checked before the three-attempt cap. Invalid guesses are not counted.
  • Decimal digits: for nonnegative remaining value n, unsigned division gives n = 10 × quotient + remainder, with remainder 0–9. Add the remainder and replace n with the quotient. Positive n strictly decreases, so at most ten digit extractions are needed in the supported domain.
Before a 64-bit unsigned DIV, clear RDX so the dividend is the intended value in RAX. Save the quotient, remainder or sum before any output helper that could clobber working registers or flags. The sum is preserved across final label printing. Do not use a negative value’s absolute value as a substitute for validating the domain.
The two condition-timing examples solve different problems; moving a test alone does not turn one into the other. The digit posttest is a comparison only. The Sum of Digits task retains its required pretest on the actual remaining value.
