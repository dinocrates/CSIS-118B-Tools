CSIS 118B · UNIT 6

Which comparison runs next?

Trace two alternatives, an ordered ladder, and short-circuit AND / OR. Predict the message, then follow the decision one comparison at a time.

This teaching simulation follows four fixed examples from the conditional-decisions lesson. It does not assemble arbitrary code or execute library calls. Numeric inputs use exact signed 64-bit integers; the grade ladder uses one printable ASCII character.

1. Choose a decision

2. Compare, jump, continue

Each step pairs one CMP or TEST with its immediate conditional jump. PENDING means not reached yet; EXECUTED means evaluated; SKIPPED means the answer was already known. Skipped comparisons do not produce new flags.

3. One selected outcome

Other outcome bodies are skipped. All paths reach show after selecting a message. Printing happens after the decision, so a helper call cannot destroy flags before the jump uses them.


Read the structure, not just the mnemonic
  • Two-way: TEST x, 1 checks the low bit. Negative integers can be odd or even. JE and JZ are equivalent names here.
  • Ordered ladder: first match wins. Uppercase and lowercase are different character codes. An unknown character reaches the default; it is not silently classified as F.
  • AND: stop when a requirement is false. The jumps test failure: JL rejects x < 1; JG rejects x > 10.
  • OR: stop when an alternative is true. The same JL/JG branches now answer the complementary outside question. Both endpoints belong inside.
“Skipped” does not mean “false.” The program did not evaluate that comparison. CMP/TEST leave the operands unchanged; the displayed instruction fragments assume input already in RAX or AL. Use the complete lesson programs to run them in the course playground.
