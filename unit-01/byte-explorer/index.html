Byte Explorer

Build an 8-bit pattern and read it four ways: binary, hex, unsigned decimal, and signed two's-complement decimal.

How to use this tool

  • Click any bit button below to flip it, or load a value by decimal, binary, or hex.
  • Watch all four representations update together — they are the same 8 bits, read four ways.
  • Use Two's-complement negate to see invert-then-add-one step by step.

Place-value sum (unsigned)

Signed reading: if bit 7 is 1, the weight of bit 7 is −128 instead of +128, and the signed value equals the unsigned value minus 256. If bit 7 is 0, the signed and unsigned values are identical.
