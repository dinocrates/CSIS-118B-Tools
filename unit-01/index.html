Unit 1 — Binary, Hex, and Fixed-Width Arithmetic

Four standalone browser tools. Each one works on its own page and can also be embedded in a Canvas page.

Byte Explorer

Build an 8-bit pattern and read it as binary, hex, unsigned decimal, and signed two's-complement decimal — plus a step-by-step two's-complement negate.

Open tool

Binary Addition with Carries

Add two fixed-width binary numbers column by column, predicting each bit before revealing it, with carry-out and signed-overflow explained separately.

Open tool

Bitwise Workbench

Apply AND, OR, XOR, and NOT to two 8-bit values, with a truth table and a per-bit explanation for every result bit.

Open tool

Binary Fraction Builder

Convert an exact decimal fraction to binary by repeated doubling, with exact detection of termination versus a repeating pattern.

Open tool
