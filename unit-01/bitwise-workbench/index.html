Bitwise Workbench

Apply AND, OR, XOR, or NOT to two 8-bit values, one bit position at a time.

How to use this tool

  • Click bits in A or B to edit them, or load decimal/hex values with the selector below.
  • Choose an operation. NOT uses only A — B is disabled and explained as unused.
  • Click (or tab to and press Enter/Space on) any result bit to see exactly how it was computed, matched against the truth table row.
