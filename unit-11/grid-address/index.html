Linear memory order

Keep the units distinct
Row stride = columns × element width. Element index = row × columns + column. Byte offset = element index × width. Address = base + byte offset. A coordinate such as (0,3) in a 2 by 3 grid is invalid even though flattening it would reach allocated bytes in row 1. Validate each dimension first.
LEA obtains an address; a memory load reads a value. Use a base register before indexed addressing; RIP-relative addressing cannot also encode a scaled index. Negative values are sign-extended by the appropriate load. Invalid coordinates produce no selected address or value. Real out-of-bounds access has no defined array result.
